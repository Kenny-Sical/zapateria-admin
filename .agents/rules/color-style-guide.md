# Guía de colores — Lizz Glamour

Esta guía define la paleta de colores oficial que debe utilizarse en la interfaz administrativa de **Lizz Glamour**. El objetivo es mantener una identidad visual coherente con la marca, utilizando principalmente tonos rosados y fucsias, pero manteniendo una interfaz limpia, profesional, moderna y fácil de utilizar.

## Paleta principal

| Elemento               | Color                   | HEX       |
| ---------------------- | ----------------------- | --------- |
| Fondo general          | Rosa grisáceo muy claro | `#F7F7F8` |
| Sidebar                | Blanco                  | `#FFFFFF` |
| Tarjetas y superficies | Blanco                  | `#FFFFFF` |
| Texto principal        | Negro suave             | `#1F1F1F` |
| Texto secundario       | Gris                    | `#6B6B6B` |
| Color principal        | Fucsia / magenta        | `#D91470` |
| Hover                  | Fucsia oscuro           | `#C51668` |
| Rosa suave             | Rosa muy claro          | `#FCE7F0` |
| Bordes                 | Gris muy claro          | `#E5E5E7` |
| Éxito                  | Verde                   | `#22A06B` |
| Advertencia            | Amarillo / naranja      | `#E6A21A` |
| Error                  | Rojo                    | `#D64545` |

## Reglas de uso

### Color principal — `#D91470`

Utilizar como color principal de la identidad visual de Lizz Glamour.

Debe utilizarse principalmente en:

- Botones principales.
- Elementos activos del menú lateral.
- Enlaces importantes.
- Iconos destacados.
- Indicadores y elementos interactivos.
- Elementos visuales que necesiten llamar la atención.
- Componentes relacionados directamente con acciones principales.

No utilizar este color como fondo de grandes áreas de la interfaz.

### Hover — `#C51668`

Utilizar `#C51668` para estados **hover**, principalmente en:

- Botones.
- Enlaces.
- Elementos interactivos.
- Opciones del menú lateral.

El estado hover debe proporcionar una diferencia visual clara respecto al color principal.

### Rosa suave — `#FCE7F0`

Utilizar como color de apoyo para crear contraste visual sin saturar la interfaz.

Puede utilizarse en:

- Fondos de pequeños bloques informativos.
- Estados seleccionados.
- Badges.
- Áreas relacionadas con la identidad de marca.
- Fondos suaves detrás de iconos.
- Destacados secundarios.

### Fondo general — `#F7F7F8`

Debe utilizarse como fondo principal de las páginas administrativas.

La interfaz debe mantener una apariencia clara y limpia, evitando utilizar colores saturados como fondo general.

### Blanco — `#FFFFFF`

Utilizar para:

- Sidebar.
- Tarjetas.
- Formularios.
- Modales.
- Tablas.
- Contenedores principales.
- Superficies que necesiten destacar sobre el fondo general.

### Texto

El texto principal debe utilizar `#1F1F1F`.

El texto secundario, descripciones, información auxiliar y contenido de menor importancia debe utilizar `#6B6B6B`.

Evitar utilizar el fucsia como color para grandes cantidades de texto, ya que debe reservarse principalmente para acciones y elementos destacados.

### Bordes — `#E5E5E7`

Utilizar para:

- Bordes de tarjetas.
- Campos de formularios.
- Tablas.
- Separadores.
- Elementos de navegación.

Los bordes deben ser sutiles y no competir visualmente con el contenido.

## Estados del sistema

Utilizar los siguientes colores exclusivamente para comunicar estados:

- **Éxito:** `#22A06B`
- **Advertencia:** `#E6A21A`
- **Error:** `#D64545`

Estos colores deben utilizarse en alertas, mensajes, indicadores, badges, validaciones y estados correspondientes.

## Principio general de diseño

La interfaz administrativa debe transmitir una sensación de **elegancia, limpieza, modernidad y profesionalismo**, manteniendo la identidad visual de Lizz Glamour.

El fucsia `#D91470` debe funcionar como el color de identidad y acción, mientras que el blanco, gris claro y negro suave deben formar la estructura principal de la interfaz.

**No utilizar el fucsia o los tonos rosados como fondo predominante de toda la aplicación.** Los colores de marca deben utilizarse estratégicamente para destacar acciones y elementos importantes.

Todas las nuevas pantallas, componentes, botones, formularios, tablas, modales y elementos de navegación deben respetar esta paleta para mantener consistencia visual en todo el sistema.
